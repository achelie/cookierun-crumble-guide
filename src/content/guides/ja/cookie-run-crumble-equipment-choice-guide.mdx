装備が2つ並び、片方は戦闘力が上がる。もう片方なら、チームに必要な命中と集中を残せる。どちらを選ぶべきでしょうか？

オーブンレベル10前後までは、高戦闘力の装備を選ぶ方法で進めやすいです。それ以降は、まず戦闘力の差を見ます。近い数値なら命中不足を直し、その後に集中、スキル増幅、スキル加速を検討しましょう。攻撃が安定して当たるなら、命中の追加は後回しにできます。

外れなくなった後も命中ばかり選ぶと、毒を重ねるのに役立つ集中オプションを逃してしまうかもしれません。

<GuideSection id="left-or-right" title="今の問題を直せる装備を選ぶ">

ステージ攻略では、次の順番を目安にします。普段の装備比較に使う基準であり、戦闘力が少し上がるたびに交換すべきという意味ではありません。

| 今の状況 | 優先するもの |
| --- | --- |
| オーブンレベルが約10未満 | 序盤を速く進める高戦闘力装備 |
| 片方で戦闘力が大きく増える | 戦闘力上昇を検討し、失う有用な能力も確認 |
| 戦闘力が近く、攻撃がよく外れる | 命中 |
| 攻撃は当たるが重要なデバフが不安定 | 集中。戦闘力不足も同時に確認 |
| 命中もデバフも安定している | ステージ向けの基本はスキル増幅、その後にスキル加速 |
| 本領を発揮する前に倒れる | 攻撃系を増やすよりダメージ減少を試す |

ここでいう「戦闘力が大きく増える」に固定の割合はありません。今のステージと、ほかの能力をどれだけ失うかで考えます。主な命中オプションを失う小幅な更新は、序盤の明らかな強化より慎重に比べましょう。

編成自体も確認してください。育成先をまだ選んでいるなら、あまり使わないクッキー向けに素材を使う前に[クッキー最強ランキング](/ja/tier-list/)を見ましょう。誰にその能力を使わせるか決まると、装備も選びやすくなります。

</GuideSection>

<GuideSection id="accuracy-check" title="火力を追う前に攻撃の外れを直す">

攻撃が外れると、付いているデバフも入れられません。命中は本人のダメージだけの問題ではありません。デバフが外れると、味方全体が必要な効果なしで攻撃することになります。

クッキーの詳細能力を開き、命中と集中までスクロールして数値を確認します。そのうえで戦闘を見ましょう。「Miss」が頻繁に出るなら、装備比較画面だけでは分からない問題が起きています。

チャプター200付近では、命中900程度が確認の出発点になります。ただし、全ステージ共通の最低値や上限ではありません。ステージと研究で必要な比較は変わります。もっと序盤のアカウントに必要な量を、そのまま示す数値でもありません。

左の装備は戦闘力が少し上がる代わりに命中が落ち、右なら命中を保てるとします。すでに外れで戦闘が止まるなら、右を優先しましょう。安定して当たり、命中に余裕があるなら、ほかの能力を比べます。いつまでも命中を選び続ける必要はありません。

どちらが不足しているか分からない場合は、[命中と集中のガイド](/ja/guides/cookie-run-crumble-accuracy-focus-guide/)で2つの違いを確認してください。

</GuideSection>

<GuideSection id="focus-and-power" title="集中は他人の数値ではなくステージと比べる">

集中には、同じように分かりやすい共通目標がありません。ステージに対する戦闘力によって、デバフの入りやすさも変わります。育成が進んだアカウントは、弱いアカウントより集中が少なくても、安定して入れられることがあります。

強いアカウントと同じ集中にしても、10段階まで重ねたい毒が4段階や6段階で止まることがあります。集中を増やすと改善する可能性はありますが、戦闘力差も引き続き重要です。

デバフを軸にするチームでは、毎回同じ場面の重複数や効果を見ます。攻撃は当たるのにデバフが繰り返し失敗するなら、集中オプションを比べましょう。たまたま勝った1回だけで決めず、同じステージとメンバーで繰り返し、安定したかを確認します。

難所の初回クリアなら、多少のやり直しを受け入れる場合もあります。しかし、日々の周回で繰り返すのは大変です。見た目では攻撃的な装備に劣っても、安定周回にできる集中装備は残す価値があります。

[おすすめ編成](/ja/teams/)で、自分のチームが毒、防御力減少、ほかのデバフにどれだけ頼るか確認しましょう。その編成を助ける装備でも、別のチームでは重要度が変わります。

</GuideSection>

<GuideSection id="enhancement-order" title="まず全体を+10、その後に+15へ進める">

1部位を+15に集中する前に、全体の装備枠を+10へ上げます。その後のステージ攻略では、命中、集中の順が実用的な出発点です。次は基本的にスキル増幅ですが、火力への投資が必要なら武器を先に強化する方法もあります。

いずれは残りの装備も強化します。全部に使える素材がない間に、次の素材をどこへ使うと一番助かるか、という優先順です。

この進め方では、防御力、HP、回避は後半に回します。戦闘力の伸びが比較的小さいためです。ただし、耐久を無視するという意味ではありません。早く倒れるなら戦闘を見直し、一覧の順番にこだわらずダメージ減少を試しましょう。

装備の強化順とシュガールーンの選択は分けて考えます。判断も素材も違います。このオーブンでの装備比較から先へ進み、各クッキー向けに調整する場合は、[装備とシュガールーンのガイド](/ja/guides/cookie-run-crumble-gear-sugar-rune-stats-guide/)で役割ごとの能力を確認してください。

</GuideSection>

<GuideSection id="arena-presets" title="アリーナは優先順を変え、保存枠も確認する">

アリーナ装備は、スキル増幅、スキル加速から始めます。次にクリティカルダメージとクリティカル率、その後にダメージ減少とクリティカル抵抗です。装備集めの実用的な順番であり、1つの能力がすべての相手に勝つという保証ではありません。

別のアリーナ用セットに生地を使う前に、どの装備プリセットへ獲得装備が入るかを確認しましょう。ここで説明する保存枠の仕組みでは、よい装備をセット間で自由に移せません。メイン装備がまだ不足しているのに、貴重なステージ向け装備がPvP用へ入ると困ります。

素材が限られるなら、まず使えるメインセットを作るほうが無難です。アリーナ用も作る場合は、装備集めの前と戦闘の前に、選択中のプリセットを確認してください。

<GuideTip title="戦闘力が急に落ちたら？">

何かを交換する前に、有効な装備プリセットを見ましょう。クッキーを替えていなくても、弱いセットへ切り替わるだけで戦闘力は落ちます。

</GuideTip>

</GuideSection>

<GuideSection id="eternal-filter" title="ETERNALだけを合格にしない">

同じくらい強化した装備なら、ETERNALは能力値がかなり高くなることがあります。ただし出にくいため、普段の装備集めでそれだけを狙うのは大変です。1個を待つ間に大量の生地を使う場合もあります。

装備集めのレア度条件は、今入手できる最高レア度より1段階下に設定しましょう。上の装備を待ちながら、次点の良品も残せます。オーブンで新しい段階が解放されたら、設定も見直してください。以前の条件が今も最適とは限りません。

装備レベルが高いと能力値も上がるため、見た目だけで捨てず数字を読みます。強化段階も比べましょう。単に強化済みだから高いのか、元の装備がよいのかを見分けることが大切です。

次の装備を引く前に、今の命中と集中を控えておきましょう。交換したら、次の挑戦ではメンバーとペットを固定します。強化素材を使う前に、攻撃の外れやデバフの失敗が減ったかを見てください。

</GuideSection>

<GuideSection id="equipment-faq" title="装備選び：よくある質問">

### 戦闘力が高い装備を毎回残せばよいですか？

いいえ。オーブンレベル10前後までは手早い選び方になります。それ以降は大きな戦闘力上昇と有用な能力を比べます。近い戦闘力なら、命中不足を直し、その後に集中、スキル増幅、スキル加速を検討しましょう。

### 命中900ならすべてのステージで足りますか？

いいえ。900程度はチャプター200付近の目安であり、全ステージの要求値や上限ではありません。今のステージ、研究、実際の攻撃の外れを見て、追加が必要か判断します。

### 集中はいくつを目指せばよいですか？

共通の目標値はありません。ステージに対する戦闘力もデバフの安定性に関わります。必要なデバフを観察し、同じ戦闘条件で集中の強化を比べてください。

### どの装備を最初に+15へ上げますか？

まず全体を+10にします。ステージ攻略では命中、集中、基本的にはスキル増幅の順です。武器を先に強化する方法もあります。耐久に問題がなければ、防御力、HP、回避は後に回しましょう。

</GuideSection>
