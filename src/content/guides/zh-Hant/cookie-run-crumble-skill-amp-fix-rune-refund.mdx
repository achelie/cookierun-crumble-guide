技能增幅以前幾乎是每個糖符文問題的懶答案。輸出？加增幅。補師？加增幅。只靠一行減益有用？也塞增幅。八月 27 日調整終於畫了界線，幾套熟悉配置不再拿到當初想洗的效果。

這不代表增幅變差到不能用，而是不能再強化特定減益，降防也不能把敵人 DEF 壓到零以下。當初就為那條減益洗增幅，符文現在需要新工作。

<GuideSection id="what-changed" title="技能增幅修正改了什麼">

兩條戰鬥規則一起變。第一，降防能到零 DEF，不能再負防。修正前疊夠降防，防禦歸零後還能讓敵人多受傷，PvE、PvP 都能用，所以減益手收益比技能文字看起來多。

第二，增幅不再強化降低敵方數值的效果，降攻、降防、降命中等用標示值。受影響的受到傷害減少，也套相同限制。技能允許時，傷害、回血、盾與適用增益仍會提升。重洗前逐行讀。

<GuideTip title="讀完技能再拆符文">

別每隻都拔增幅，先查技能哪段吃。補師或輸出可能仍拿完整效益，純數值減益手卻幾乎沒拿到有用收益。

</GuideTip>

</GuideSection>

<GuideSection id="affected-cookies" title="這 11 隻先查符文">

原退款整理列出 11 隻。不過勇敢餅乾這一項要回原公告核對：目前遊戲資料顯示，降攻技能屬於活潑餅乾。下面的配裝檢查仍適用：

- 惡魔、鬆餅與黑巧克力用降防。
- 洋蔥餅乾會降攻，勇敢餅乾不會；目前資料把這個減益放在活潑餅乾身上。依照下面的歷史名單判斷退款前，先核對原公告的名字。
- 可可、天使、離子機器人與無名蛋糕犬，有受影響防禦效果。
- 泡泡糖與吸血鬼帶其他不再照舊吃增幅的數值減少。

這是查配置的理由，不是要這 11 隻全坐板凳。黑巧克力仍降防，離子仍是硬防守，火前排合隊時蛋糕犬仍有工作。改的是增幅和過度疊同類減少的回報。

花新材料前，看各隻目前[薑餅人放置大戰爭 強度榜](/tier-list/) 位置。有多份實用工作的，較能吸收某個互動變弱；只靠一招減益的，就難說服人。

</GuideSection>

<GuideSection id="defense-floor" title="別再替負 DEF 付錢">

零 DEF 底線懲罰重疊。黑巧克力與惡魔已把王防禦清光，更多降防不能靠負防再加傷。空出的格，可能放暴擊支援、屬性傷害、補師，或能活到第二招的人更值。

低 DEF 目標與疊多層減少的隊最有感。高 DEF 王仍給降防很多工作。固定同關同寵，看通關時間，別只信戰鬥力。幾乎沒變，代表沒靠負防吃飯；傷害斷崖式下滑，舊互動做的工作比名單承認得多。

[命中與專注攻略](/guides/cookie-run-crumble-accuracy-focus-guide/) 仍重要。專注幫減益上去，不會把減益變強，也不能突破新 DEF 底線。

</GuideSection>

<GuideSection id="devil-cookie-build" title="惡魔失去最簡單的配法">

惡魔最傷，因為主要上場理由是降防。個傷普通、又脆，隊伍常多花一格照顧他。以前增幅能強化值得這樣照顧的減益，現在只剩通常付不起符文成本的小增傷。

先往生存走。HP、DEF、減傷讓他活到重要施法。第一個減益結束後再補有用，加速值得測；敵人抵抗高，專注仍有用途。除非以後平衡增加別的適用效果，否則很難替全增幅辯護。

也不是自動沒用。王 DEF 夠高、壓力夠低，減少仍值得。太早死，或別人已做到零 DEF，就換。

</GuideSection>

<GuideSection id="tank-builds" title="離子與防禦組，小心調整">

離子說明為什麼全員重置很蠢。增幅可能仍幫適用盾或其他部分，卻不強化受影響減傷。舊裝主要為拉長那個防禦效果，就試坦裝或加速，比完整一場生存。

可可、天使、蛋糕犬也逐效果讀。其餘回血、盾、傷害或增益仍值，就留增幅；被排除那行本來是整個理由，才換。

[裝備與糖符文攻略](/guides/cookie-run-crumble-gear-sugar-rune-stats-guide/) 有安全重洗順序，一次鎖一條強詞條。退款當天想重建四坦，很容易把補償變新缺口。

</GuideSection>

<GuideSection id="pinot-noir-rule" title="黑皮諾上線時就照這規則">

黑皮諾不在退款組，因為技能推出時文字已列限制。技能增幅不提高減療，原本標示值已足以壓補師隊。

他的擊飛抵抗增加也不吃增幅，別為強化減療或抵抗而保留這條。敵人抵抗減益，專注能幫；重要效果覆蓋本來好，加速收益有限。

更新後的[黑皮諾配裝](/guides/cookie-run-crumble-pinot-noir-cookie-build/) 分清工作，讓你選能解目前問題的詞條。

</GuideSection>

<GuideSection id="rune-refund" title="九月 1 日退款，別一次亂洗光">

公告的退款日期是九月 1 日，返還列出餅乾花過的糖符文重洗材料，讓受影響帳號不用為修正前不清楚的規則付兩次錢。

改之前每套截圖，寫替代數值與上場內容。收到後先重建一隻常用角、測完再動下一個。別為追補償現在額外洗，退款不會讓爛詞條變有用，最後一刻花費也未必照你期待計算。

惡魔顯然先查；離子、黑巧克力、蛋糕犬若跨多套，接著顧。等級 20 坐著沒用的可以等，紅點不耐煩不代表退款要過期。

</GuideSection>

<GuideSection id="rebuild-checklist" title="修正後的實用隊伍檢查">

1. 標出預設內每個受影響餅乾。
2. 查是否兩隻以上對同目標重疊降防。
3. 改符文前先打一個熟悉王或關，記通關時間。
4. 只有被排除效果是配裝主因時，才換技能增幅。
5. 新裝重打同場，再動另一隻。

舊預設少太多傷害，用已測[薑餅人放置大戰爭 隊伍](/teams/) 當基準，一次換一格。同時換惡魔、三寵、重洗離子，只能知道結果不同，找不到原因。

</GuideSection>

<GuideSection id="skill-amp-faq" title="技能增幅修正常見問題">

### 技能增幅被削弱了嗎？

仍加傷害、回血、盾和適用增益，不再強化降低敵方數值的減益，降防也不能到負 DEF。範圍變窄，並非無用。

### 哪些餅乾能退糖符文材料？

原退款整理列出惡魔、鬆餅、黑巧克力、勇敢、洋蔥、可可、天使、離子機器人、無名蛋糕犬、泡泡糖、吸血鬼。勇敢餅乾這一項要回原公告核對：目前遊戲資料顯示，降攻技能屬於活潑餅乾。

### 惡魔還值得用嗎？

敵方 DEF 夠高仍可幫，但增幅不再加強主要減益。先活得住穩放，再依戰鬥測專注或加速。

### 糖符文什麼時候退款？

公告時程是九月 1 日，涵蓋列出受影響餅乾的糖符文重洗投資。

### 增幅會提高黑皮諾減療嗎？

不會。減療與擊飛抵抗都忽略增幅，別為強化它們洗；敵方抵抗擋減益時，用專注處理。

</GuideSection>
