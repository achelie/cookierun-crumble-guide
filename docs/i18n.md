# 全站语言维护

英语保留原路径；繁中、日语、韩语、泰语分别使用 `/zh-tw/`、`/ja/`、`/ko/`、`/th/`。语言类型与资料站使用 `zh-Hant`，网页语言也设为 `zh-Hant`；内容以台湾用语为主，供香港玩家阅读。网址决定语言，不按浏览器语言自动跳转。

## 内容与来源

- `src/i18n/source/manifest.json`：离线快照版本、来源日期与覆盖数量。当前游戏数据版本 `1.5.002`，资料日期 `2026-10-14`。
- `src/i18n/source/{locale}.json`：游戏词条、术语、实体译名及逐条来源键。`entities.json` 按 resourceKey 保存多语言名称；本站 77 个角色和 57 个宠物全部有对应项，特殊 ID `chardonnay` 对应 `cookie4011`。
- `src/i18n/messages/{locale}.json`：运行时文案与逐条来源/复核状态。`native-reviewed` 表示按目标语言表达复核的补译；`game-localization`、`game-entity` 等可回溯至游戏词条。
- `src/i18n/overrides/{locale}.json`：持久保存的编辑修订。补译脚本只处理缺失键，不覆盖已有正文；不要把这些修订移回被 Git 忽略的 `output/`。
- `src/content/guides/{locale}/`：每种语言 28 篇全文，共 112 篇。原发布日期由共享注册表提供。章节 ID、阵容、数字、图片和 slug 与英语对应。
- `public/data/tools/{locale}/`：三种计算器与角色目录的本地化离线数据；数字、ID、存储字段和算法保持兼容。
- `src/i18n/source/corrections.json`：发现的原文事实问题及处理依据。Pinot 的两项效果不吃技能增幅；历史退款名单的角色名称与当前技能数据存在出入，页面明确说明核对范围，没有据此编造历史退款资格。

构建和浏览网站都不访问 `127.0.0.1:6868`，也不调用千问。资料站与翻译服务仅用于明确执行的内容维护任务。

## 页面接入

`I18nElement`、`LocaleLink`、`LocaleImage` 在渲染时处理显示文字和页面链接，表单值、实体 ID 与计算参数保持原值。新 JSX 文字使用这些组件；需要搜索的实体同时使用多语言别名。MDX 正文从目标语言文件加载，内部链接由统一的 MDX 组件保持当前语言。

`src/app/[locale]/` 只保留薄路由，页面组件与英语共用。两组独立根布局继续区分有广告和无广告页面。新增路由后更新 `scripts/i18n/routes.mjs`；路由段配置必须直接导出字面量，不能重导出 `dynamicParams`。

SEO 使用同一套语言路径映射生成 canonical、完整双向 hreflang、英语 x-default 和 sitemap。每个正式页面都有本地化标题、描述、正文及结构化数据。工具导入器会接入语言参数，并限制导入样式的文字不超过 26px；强度榜既有 S–D 档位标签保留例外。

## 常用维护命令

```powershell
# 显式更新资料站快照；不是构建步骤。先保留并检查已有语言文件。
node scripts/i18n/prepare.mjs

# 追加新界面/SEO文案，复用已完成攻略里的标题与 FAQ
node scripts/i18n/augment.mjs
node scripts/i18n/extract-guide-messages.mjs ja
node scripts/i18n/fill-sourced.mjs

# 可选：使用已配置的翻译服务，只补缺失词条
# API key 只从环境读取，不写入项目文件。
node scripts/i18n/translate.mjs th --ui-only

# 合并编辑修订并重新生成本地化工具数据
node scripts/i18n/finalize.mjs

# 离线完整性、实体、数字、MDX、链接和计算数据检查
npm run verify:i18n
npm test
npx tsc --noEmit
npm run build
node scripts/verify-i18n-static.mjs
node scripts/verify-tools-static.mjs
# 构建已自动检查实际生成页面；也可单独重跑
npm run verify:i18n:rendered
# 浏览器复验后，可带上该次采集的运行状态文件
node scripts/verify-i18n-rendered.mjs --runtime output/i18n/runtime-coverage-final.json
```

`prepare.mjs` 会刷新源文案库存；已经完成的语言包和译稿是需要保留的编辑资产。若只更新英语攻略段落，可运行 `refresh-guides.mjs`，无需重拉全部资料。新增攻略后执行 `guide-loaders.mjs` 生成静态导入。

翻译服务遇到欠费或认证错误会停止发出后续请求；现有文件和缓存保留。正常构建有完整性门禁，缺少文案或正文会失败。可选的 `social-images.ps1` 使用 Windows 本地字体生成分享 PNG，生成结果已保存，普通构建不需要这些字体。

## 验证记录

最终记录见 `docs/i18n-verification.json`。Google Trends 的 8 组观察、相对指数 CSV 和 180 个新增语言页面的意图映射见 `docs/seo/keyword-research-2026-10-17.md`。长尾数据不足的词明确标为辅助、尚未验证，不能当作月搜索量。

2026-10-17 的二次翻译复查见 `docs/i18n-audit-2026-10-17.md`。必需文案现为每种语言 2,428 条。新检查覆盖短标签、图片与读屏属性、结构化数据及计算器校验错误；保留品牌、游戏别称、缩写和原始数据字段的明确清单在 `scripts/i18n/rendered-text.mjs`，普通界面词不能加入清单来绕过漏译检查。动态提示优先用 `formatMessage(t, key, ...values)` 填入参数，避免角色名里的句点影响模板匹配。

Next 16 的静态导出开发模式会把未知攻略参数报成 500，因此开发环境使用普通路由，生产构建仍导出静态文件；两种环境的未知路径均已验证为 404。构建仍会打印部分 metadataBase 提示，最终生成的 225 页元数据均已检查为生产域名，没有 localhost 链接。
